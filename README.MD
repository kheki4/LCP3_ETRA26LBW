## LCP3_ETRA26LBW

This is an import of the LCP3:
https://github.com/kheki4/LCP3
Importantly, there have been several small changes yet to be committed on the LCP3 repo since its release, and this repository already shows some of them. However here it is only intended to provide a quick way to reproduce preproccessing and statistics results for my ETRA2026 late-breaking work. (A proper update and cleaner version of LCP3 will be committed some time this year.)

Eye data used (without image content) are also included.

Experimental scripts used to present stimuli can be found in [Experimental_scripts](Experimental_scripts).

Shapiro normality test implementation was used from [https://www.mathworks.com/matlabcentral/fileexchange/13964-shapiro-wilk-and-shapiro-francia-normality-tests](https://www.mathworks.com/matlabcentral/fileexchange/13964-shapiro-wilk-and-shapiro-francia-normality-tests) written by Ahmed BenSaïda. (Last accessed: 2026.01.12. 17:25 CET). License to it can be found in [3rdparty_licenses/license_swtest.txt](3rdparty_licenses/license_swtest.txt).

The scripts only work with Matlab yet.
